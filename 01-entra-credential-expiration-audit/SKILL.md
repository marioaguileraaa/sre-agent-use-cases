# Entra Full Credential Inventory Audit

## Objective
Produce a monthly expiration audit of Microsoft Entra credentials.

## Scope
- Include Application Registrations.
- Include Service Principals.
- Exclude Service Principals whose `servicePrincipalType` is `ManagedIdentity`.
- Do not include federated identity credentials.
- Do not make any change in Entra ID or in Azure.

## Mandatory tool
Use `generate-entra-credential-expiration`.

## Security
- Read-only.
- Never display, store or log tokens, secrets, `secretText`, certificate content, private keys or unfiltered Graph responses.
- An authentication, permission or pagination error is not the same as an empty inventory.

## Validation
Require and report:
- Applications discovered.
- Service Principals discovered.
- Managed Identities excluded.
- Pagination completed for both inventories.
- Complete or partial coverage.
- Count by risk status.

## Classification
Use a single UTC instant:
- EXPIRED: <= 0 days.
- CRITICAL: 1-7 days.
- EXPIRING SOON: 8-30 days.
- EXPIRING: 31-90 days.
- Valid: > 90 days.

## Output
Deliver:
1. The HTML file generated by the tool.
2. A concise executive summary.
3. Coverage.
4. Counts by status.
5. Action required if there are EXPIRED or CRITICAL credentials, or if coverage is partial.
