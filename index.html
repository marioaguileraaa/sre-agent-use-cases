About this guide

Every plate is a real use case of Azure SRE Agent, built and tested with customers and written up as a step-by-step guide with annotated screenshots.

All of them are read-only by design. The agent reads, explains and proposes; a person decides and makes any change.

The guide keeps itself up to date: a new use case appears here as soon as it is added to the repository.

How every use case is built

  1. Python toolreads the data and writes the report
  2. Skillthe rules for running it and presenting the result
  3. Subagenta dedicated specialist with only that skill and tool
  4. Scheduled taskruns it every month or week, on its own
